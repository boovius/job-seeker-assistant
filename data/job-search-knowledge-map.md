# Job Search Knowledge Map

This file is the quick index for the job-search memory stack in this repo.

## Canonical Use

- `data/experience/experience-database.md`
  - Use for structured facts, canonical role entries, resume evidence, source-traceable details, and open gaps that still need stronger metrics or examples.
- `data/experience/experience-repository.md`
  - Use for broader positioning, professional narrative, strength themes, bios, and higher-level framing about where Josh creates leverage.
- `data/stars/stars-database.md`
  - Use for reusable STAR stories, interview examples, application-question support, and resume bullets that need stronger narrative proof.

## Current Relationship Between Files

- `experience-database.md` is the best source when a resume or tailored application needs concrete factual support.
- `experience-repository.md` is the best source when a bio, summary, or positioning document needs a coherent professional story.
- `stars-database.md` is the best source when interview prep or application writing needs a clear situation-action-result narrative.

## Repo Mirror Notes

- The repo copies are intended to keep job-search knowledge close to the resume/application workflow.
- Workspace copies may still be edited first in some sessions, so these repo files should be treated as mirrors that need occasional sync when the job-search knowledge base changes.
